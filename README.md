# 2048-game
这是一个由`c++`语言编写、轻量、带色彩的2048

至少需要 **$\text{c++11}$**

无第三方库
## 存档储存方式
1. `2048.sav` : 在每次非断电退出时保存的存档
2. `2048.sav_old` : 在每次存档时候会备份上一次存档
## 含有版本
1. $\text{Win7+}$  使用原生API
2. $\text{Win10+}$  使用VT模式，无刷屏
3. $\text{linux}$ 使用原生VT
4. $\text{windows10+ and linux}$ 跨平台(因水平原因，无法融入Win7)
## 游戏规则
1. $\text{退出}$ : 关闭游戏窗口或按`ESC`键即可，只要是非断电方式关机，也能存档
2. $\text{玩}$ : 方向键控制方块
